# Wisdom in the Age of AI: Conference Schedule

A single-page view of the [Wisdom in the Age of AI](https://calvin.edu/faith-and-technology/faith-and-ai-conference) conference schedule (Calvin University, October 8-10, 2026). Parallel tracks are shown side by side as columns, with every talk title, time and speaker. Session and talk names link to their pages on Whova.

The data is a snapshot of the conference's public Whova agenda taken on October 8, 2026. The schedule is tentative, so check the official agenda for changes.

No build step: `index.html` is self-contained apart from Google Fonts.
